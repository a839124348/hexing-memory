OneBot NAP CAT / LLONEBOT

自己准备 QQ 小号、基座和 OneBot 11 WS。基座能看到全群，但桥只处理 @；能主动、有本地历史。

  • 群：只处理 @；非 @ 不记录、不进分板
  • 私聊：进主记忆
  • 风险：账号/协议/封号，自己承担
适合：能自己维护基座、接受自己准备小号/WS；群聊仍只处理 @。

QQ 官方机器人 OFFICIAL API

在 q.qq.com 建 bot，群主把它加进群。稳定、合规，但只回 @。

  • 群：只收 @ 机器人的消息
  • 私聊：用户先私聊 bot；进主记忆
  • 限制：不做主动消息、不拉历史
需要先在 profile 配 official.appId / clientSecret。
官方机器人怎么配？

先在 q.qq.com 建机器人，拿 AppID / ClientSecret；把下面这段加进 DSH profile 的 hexing-qq config，重启 DSH。不要把这些发到群里。

transport: 'official'
ownerOpenId: '<你的 user_openid>'
official:
  appId: '<AppID>'
  clientSecret: '<ClientSecret>'
  sandbox: false
  groupNames:
    '<group_openid>': '测试群'

然后让群主把机器人加进群。官方只收 @ 机器人的消息；不拉历史、不做主动消息。ownerOpenId 用你的 QQ 私聊机器人发一句，DSH 日志里的「私聊 <openid>」就是。

模型不会连？复制这段给 AI
