# 核星记忆 · 客服问答

> 用途：给 DSH 模型 / 群客服回答群友问题。只讲公开信息，不透露 owner 私事、私聊记忆、密钥。
> 版本：v0.4.6；以 README / Release 为准。

## 一句话

核星记忆（Hexing Memory）是给 DSH 用的**开源长期记忆插件**：跨会话记得你、原文不丢、会自己整理成链网、语义检索在本地跑；MIT，免费。

## 基本

- 形态：DSH 插件（`dsh-plugin` + `dsh-plugin-ui`），核心引擎纯 JS。
- 支持：DSH 0.2.2 系列 + Node >= 24.9；Node 20/22 不支持（DSH 自身要求）。
- 仓库：https://github.com/a839124348/hexing-memory
- 数据默认在 `%APPDATA%\dsh-memory`，本地明文。

## 能做什么

- 跨会话记忆：A 会话说的事，B 会话能查回来。
- 原文不丢：聊天按天存 JSONL；提炼只是索引，细节能回原文。
- 自动提炼建链：身份 / 项目 / 学习 / 关系 / 避坑 / 存储 / 想法 / 日常 / 约定链。
- 本地语义检索：bge-small-zh-v1.5，512 维；不把记忆传到云端向量库。
- 总览页 + 3D 链网；迁移旧 JSONL；v0.4.5 可补旧历史链网。
- QQ 桥（可选）：owner 私聊、群 @、群友 24h 分板。

## 数据与隐私

- 明文存储、明文检索；**无加密、无脱敏、无访问控制、没有删除工具**。
- 写入后只能停 DSH 处理文件或整库删除；删除前先备份。
- 不要粘贴密码、密钥、银行卡号、身份证号。
- 群聊不进主记忆；QQ 群只做 @ 回复，群板 24h 清；私聊才进主记忆。
- 接入 QQ/微信/群聊前先读 RULES 第十六节；群聊涉及他人隐私、平台条款、封号风险。
- **群聊口径**：只解释核星记忆的公开隐私机制；不要主动说“隐私问题都可以问我”，不邀请群友问自己的私事，不记录群友私事。

## 安装

- 把仓库链接发给 DSH，让它按 `INSTALL-FOR-AI.md` 做；网络打不开 GitHub 就用 `hexing-memory-v0.4.6-full.zip`。
- 顺序：装本体 → 重启 → `memory_manual` 通读 19 节 → `memory_onboarding` 三选一 → 迁移/初始化 → 验证旧对话可搜 → 再装侧边栏入口。
- 不要手写路径、不要改 DSH 源码；路径让 `install.ps1` / `tools/make-patch.js` 生成。

## 迁移旧历史

- 旧平台导出 JSONL：一条 = 一次发言，`t/s/c/cid/v` 必填；不要总结、合并、改写。
- 先 `node tools/import-jsonl.js --file old.jsonl` 预检，再 `--apply`；重复导入不会翻倍。
- 旧历史导入的是 raw + 向量，**不会自动建链**；链网从新对话生长。
- v0.4.5 迁移补链：先 `memory_backfill action=status` 统计条数/批数/约多少 token；用户同意后再 `preview` → `start`。
- 补链 100 条/批，超过 100 条自动分块；写前备份 links；节点标 `source=migration`，时间用原对话时间。

## QQ 桥

- 可选功能；**不提供 NapCat/LLOneBot、QQ 账号、OneBot WebSocket**，用户自己准备小号/底座。
- 传输二选一：`onebot` 或 `official`；同一时间只连一个，切换要重启 DSH。
- 官方机器人：群聊只收 @，不拉历史、不主动；群主加 bot；主体认证/发布权限以平台为准。
- OneBot：能主动、有基座历史；但桥只处理 @，非 @ 不进分板；有账号/协议/封号风险。
- 群聊不建 DSH 群会话（stateless），只写群友 24h @ 分板；私聊 `qq:owner` 进主记忆。
- 群主不加 bot / 不开权限，就没有群入口；不要代登录、代扫码、代开端口。

## 常见问题

**收费吗？**  
MIT，免费；模型、服务器、QQ 账号等成本自己承担。

**会上传记忆吗？**  
语义检索在本地跑，不把记忆传到云端向量库；模型调用是否联网看 DSH 的模型配置。

**能删除吗？**  
没有删除工具；停 DSH 后处理文件或整库删除；先备份。群板 24h 自动清。

**为什么搜不到？**  
先看向量服务健康/是否 `degraded`；草稿 ≠ 存档；用 `memory_search` 查原文；旧历史要先导入，链网要补链或等新对话。

**记忆不准？**  
链头/摘要是索引，不是原文；先查 raw 原话；摘要与原文冲突以原文为准。

**支持微信/其他平台吗？**  
当前是 DSH 插件；核心引擎纯 JS 可接其他平台，但适配要另做。

**群聊会记得吗？**  
群聊不进主记忆；只记 @ 的 24h 分板；私聊才进主记忆。

**官方 bot 怎么加群？**  
群主在群设置里加；主体认证/发布以平台为准；官方群聊只 @ 回复。

**token 消耗在哪？**  
对话本身 + 自动提炼 + 迁移补链；补链会先统计 token，用户同意再跑。

## 反馈问题

带版本号 + `node tools/diagnose.js` 输出 + `[memory-system]` 日志；**不要贴记忆原文、身份内容、API key、密码**。
