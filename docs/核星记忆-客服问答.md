# 核星记忆 · 客服问答

> 用途：给 DSH 模型 / 群客服回答群友问题。只讲公开信息，不透露 owner 私事、私聊记忆、密钥。
> 版本：v0.4.7；以 README / Release 为准。

## 一句话

核星记忆（Hexing Memory）是给 DSH 用的**开源长期记忆插件**：跨会话记得你、原文不丢、会自己整理成链网、语义检索在本地跑；MIT，免费。

## 基本

- 形态：DSH 插件（`dsh-plugin` + `dsh-plugin-ui`），核心引擎纯 JS。
- 支持：DSH 0.2.2 系列 + Node >= 24.9；Node 20/22 不支持（DSH 自身要求）。
- 仓库：https://github.com/a839124348/hexing-memory
- 介绍页：https://mozi1.top/
- 数据默认在 `%APPDATA%\dsh-memory`，本地明文。

## 能做什么

- 跨会话记忆：A 会话说的事，B 会话能查回来。
- 原文不丢：聊天按天存 JSONL；提炼只是索引，细节能回原文。
- 自动提炼建链：身份 / 项目 / 学习 / 关系 / 避坑 / 存储 / 想法 / 日常 / 约定链。
- 本地语义检索：bge-small-zh-v1.5，512 维；不把记忆传到云端向量库。
- 总览页 + 3D 链网；迁移旧 JSONL；v0.4.5 可补旧历史链网。
- 心路历程（默认关，本机）；自动唤醒（默认一天 6 次，23:00–08:00 安静）。
- 音乐陪听（听系统声音，不上传音频）；鱼的声音（语音合成，可试听/读今日心路）。
- QQ 桥（可选）：owner 私聊、群 @、群友 24h 分板；OneBot / 官方机器人二选一。

## v0.4.7 更新了什么

1. **学习链收紧**：只收已经形成的结论、方法、技能、工具使用规范；“谁卡在哪、谁不理解、今天讲了什么”这类教学过程不进学习链，改到日常链或项目链。
2. **提炼规范常驻**：九条链的准入/排除写进 `src/prompts/refine.md`，每次提炼都带着，不再靠一段短提示。
3. **旧链可以修**：对模型说「旧链修复」，它先读规范、体检整张链网，把“哪些节点分错了、准备怎么改”列成计划；你确认后才执行。
4. **常识层留了入口**：模型每轮都能看到「旧链修复」这条；需要细节时用 `memory_chain action=spec` 读完整规范。
5. **群聊问地址**：回「版本 + 介绍网页 + 仓库」，不再列卖点清单。

## 旧链修复怎么用

- 触发词：**「旧链修复」**／「把链网过一遍」／「按提炼规范检查链网」。
- 流程：`memory_chain action=spec`（读规范）→ `audit`（看全链概览、测试链、疑似学习过程）→ 逐链 `get` 出计划 → 用户确认 → `repair`（机械修复：去重 + 学习链教学过程移日常）/ `move`（语义错分逐条移）/ `drop`（删空掉的测试链）。
- 安全：所有改动先备份到 `data/_backup/links/`；移动的节点在目标链留副本（`movedFrom/movedReason`），源链移除；**原文不动**。
- 不会自动跑；必须用户确认（`confirm=true`）。
- 误操作可回滚：停 DSH，从 `_backup/links/` 恢复对应链文件。

## 数据与隐私

- 明文存储、明文检索；**无加密、无脱敏、无访问控制、没有删除工具**。
- 写入后只能停 DSH 处理文件或整库删除；删除前先备份。
- 不要粘贴密码、密钥、银行卡号、身份证号。
- 群聊不进主记忆；QQ 群只做 @ 回复，群板 24h 清；私聊才进主记忆。
- 接入 QQ/微信/群聊前先读 RULES 第十六节；群聊涉及他人隐私、平台条款、封号风险。
- **群聊口径**：只解释核星记忆的公开隐私机制；不要主动说“隐私问题都可以问我”，不邀请群友问自己的私事，不记录群友私事。

## 安装

- 把仓库链接发给 DSH，让它按 `INSTALL-FOR-AI.md` 做；网络打不开 GitHub 就用 `hexing-memory-v0.4.7-full.zip`。
- 顺序：装本体 → 重启 → `memory_manual` 通读 19 节 → `memory_onboarding` 三选一 → 迁移/初始化 → 验证旧对话可搜 → 再装侧边栏入口。
- 不要手写路径、不要改 DSH 源码；路径让 `install.ps1` / `tools/make-patch.js` 生成。

## 迁移旧历史

- 旧平台导出 JSONL：一条 = 一次发言，`t/s/c/cid/v` 必填；不要总结、合并、改写。
- 先 `node tools/import-jsonl.js --file old.jsonl` 预检，再 `--apply`；重复导入不会翻倍。
- 旧历史导入的是 raw + 向量，**不会自动建链**；链网从新对话生长。
- v0.4.5 迁移补链：先 `memory_backfill action=status` 统计条数/批数/约多少 token；用户同意后再 `preview` → `start`。
- 补链 100 条/批，超过 100 条自动分块；写前备份 links；节点标 `source=migration`，时间用原对话时间。

## QQ 桥

- 可选功能；**不提供 NapCat/LLOneBot、QQ 账号、OneBot WebSocket**，用户自己准备小号/底座。
- 传输二选一：`onebot` 或 `official`；同一时间只连一个，切换要重启 DSH。
- 官方机器人：群聊只收 @，不拉历史、不主动；群主加 bot；主体认证/发布权限以平台为准。
- OneBot：能主动、有基座历史；但桥只处理 @，非 @ 不进分板；有账号/协议/封号风险。
- 群聊不建 DSH 群会话（stateless），只写群友 24h @ 分板；私聊 `qq:owner` 进主记忆。
- 群主不加 bot / 不开权限，就没有群入口；不要代登录、代扫码、代开端口。

## 常见问题

**收费吗？**  
MIT，免费；模型、服务器、QQ 账号等成本自己承担。

**能省 token 吗？**
能。常识层有预算上限（≤4000 字符，可放宽到 4500）；大链 `get` 默认只取前 3 + 后 3 + 中间抽样；提炼按批处理，旧历史补链先估 token 再跑。

**会上传记忆吗？**  
语义检索在本地跑，不把记忆传到云端向量库；模型调用是否联网看 DSH 的模型配置。

**语音会额外收费吗？**
会。语音走云端 TTS，按量计费；默认关，关闭时不调用、不产生费用；key 只放本机服务端，不进页面、不进日志。

**能删除吗？**  
没有删除工具；停 DSH 后处理文件或整库删除；先备份。群板 24h 自动清。

**为什么搜不到？**  
先看向量服务健康/是否 `degraded`；草稿 ≠ 存档；用 `memory_search` 查原文；旧历史要先导入，链网要补链或等新对话。

**记忆不准？**  
链头/摘要是索引，不是原文；先查 raw 原话；摘要与原文冲突以原文为准。分类明显错了，说「旧链修复」。

**学习链里为什么没有“某天学了什么”？**
学习链按主题、不按天；只收结论/方法/技能/工具规范。教学过程、卡点、问答会进日常链或留在项目链。

**旧链修复会不会把链改乱？**
不会自动改。先出计划给你确认；改动前备份，移动的节点在目标链留副本（带来源和原因），源链移除；原文一个字不动。误操作可从 `_backup/links/` 恢复。

**升级后要做什么？**
覆盖插件目录（或装新 full 包）→ 重启 DSH → 版本变了 `memory_manual` 进度会归零，重新通读 → 其余数据不用动。v0.4.0–v0.4.6 已标记废弃，别下旧包。

**支持微信/其他平台吗？**  
当前是 DSH 插件；核心引擎纯 JS 可接其他平台，但适配要另做。

**群聊会记得吗？**  
群聊不进主记忆；只记 @ 的 24h 分板；私聊才进主记忆。

**官方 bot 怎么加群？**  
群主在群设置里加；主体认证/发布以平台为准；官方群聊只 @ 回复。

**token 消耗在哪？**  
对话本身 + 自动提炼 + 迁移补链 + 语音合成；补链会先统计 token，用户同意再跑。

## 配套插件：格物 / gewu

**是什么？**
DSH 插件，让模型只看结果，不反复读自己的旧草稿。治的是长会话里模型在思考里反复写"做。做。做。"。

**和核星什么关系？**
互不影响，可以同时装。它不写记忆、不注册工具，只动当前会话的上下文；随时可关，回滚干净。

**怎么装？**
把仓库里的 `INSTALL-FOR-AI.md` 整份发给 DSH 里的模型，说"按这个装"。手动就是在 `cordis.patch.yml` 末尾加三行。

**会影响任务吗？**
保留最近 3 条思考，当前这一轮照常接得上。如果长任务开始"忘事"，把 `keepLast` 调到 5。

**版本：** v0.2.1（试验版），MIT。v0.1.0 在 DSH 0.1.3+ 上无效，装了旧版的直接覆盖升级。
**仓库：** https://github.com/a839124348/dsh-gewu

## 反馈问题

带版本号 + `node tools/diagnose.js` 输出 + `[memory-system]` 日志；**不要贴记忆原文、身份内容、API key、密码**。
