# 版本卖点

> 这一页写给用户看：每个版本多了什么、为什么值得升级。  
> 技术明细和修复项见 [CHANGELOG](../CHANGELOG.md)；安装/升级见 [INSTALL-FOR-AI](../INSTALL-FOR-AI.md)。

## v0.4.4（2026-11-11）QQ 群聊 + 会话绑定

一句话：记忆系统从电脑里走到 QQ；群聊不污染主记忆，私聊可以和你常用的会话无缝衔接。

- **QQ 群聊**：一个群一个会话，群友各自 24h 分板，回复自动 @ 提问者；同群限流会排队，不丢消息。
- **群聊边界**：群内容不进主 raw/链；只介绍 `public:true` 的公开项目；私事用伴侣式/替 owner 挡回。
- **会话标题**：私聊「大号私聊会话」，群聊自动用群名，不再一堆「未命名」。
- **私聊二选一**：专用 `qq:owner`，或绑定一个已有 DSH 会话；绑定后 QQ 消息带 `[QQ私聊]`，回复能接上主会话上下文。
- **只回 QQ 轮次**：只有 QQ 触发的那一轮才回 QQ，电脑 UI 里说的话不会外发。
- **换绑边界**：换绑只切换后续消息，不迁移旧历史；旧会话保留，解绑可回去。

## v0.4.3（2026-11-10）压缩认知 + 本地时间 + 老用户修复

一句话：模型不再把“压缩”当成“丢记忆”，老数据的时间也不再偏。

- **压缩认知修正**：压缩只影响当前上下文，原文还在 raw；`<compacted-summary>` 是线索不是证据，具体事实先 `memory_search` / `memory_chain`。
- **本地时间**：链节点 `t` 用本地时间，不再 UTC 慢 8 小时；新增 `tSource` 区分 local/explicit/llm/fallback。
- **老用户修复包**：`repair/` 按「诊断 → 会话取证 → 映射修复」修链时间，默认 dry-run、写前备份、幂等，不做全库 +8。
- **日常链结构**：`rebuild-daily.js` 把扁平日常链按年/月分层，只动结构不动正文。
- **定时唤醒兼容**：DSH 原生 schedule 不再写进 raw/草稿，pre-step 显示 `[WAKE]`，只记 wake log。
- **QQ 桥骨架**：owner 私聊可选接入（NapCat/账号/OneBot WS 由用户自己准备）。

## v0.4.2（2026-11-09）首体验修正

一句话：第一次安装不再一打开总览就是 0。

- **分阶段安装**：`core` 只装插件本体，`ui` 只装侧边栏入口，`all` 一次装完；没选迁移模式时不装入口。
- **空库引导**：总览页显示「还没有开始记住任何对话」，不再只显示 0。
- **向量服务自动拉起**：首次安装依赖和模型校验通过后补写 `vector/onnx/.ready`。
- **路径自检**：能区分「还没选迁移模式」和「profile 真的缺入口」。

## v0.4.1（2026-11-09）安装体验版

一句话：把仓库链接发给 DSH，让模型自己装。

- **给 AI 的安装 runbook**：`INSTALL-FOR-AI.md`，检查环境、固定 tag、模型 SHA、DryRun/Apply、备份、重启、验证、回滚。
- **安装器**：`install.ps1` 默认 DryRun；`-Apply` 才写入；自动备份 profile、幂等插入、校验模型 SHA。
- **侧边栏入口**：DSH 里直接点「记忆总览」，不用记 3099 地址。
- **离线 full zip**：源码 + 两个向量模型打成一个包，GitHub 打不开时直接解压。

## v0.4.0（2026-11-09）首个开源 MVP

一句话：记忆不只存在当前会话。

- **三层记忆**：原文按天 JSONL 真追加、跨会话草稿板、LLM 自动提炼建链。
- **常识层**：身份 + 常驻规范 + 说明书目录 + 链网索引，≤4000 字，压缩后自动补回。
- **链网**：身份/项目/学习/关系/避坑/存储/想法/日常/约定九根默认链，最多 4 层；约定链单独根。
- **创意池 / 话题栈**：同月想法 ≥5 自动成池，立项升格项目链并保留 `promoted_to`。
- **本地语义检索**：bge-small-zh-v1.5 + XVEC，模型 SHA 校验，不依赖云端向量库。
- **看得见**：总览页（陪伴天数、token、草稿/存档/链网）、真 3D 链网、迁移问卷和 JSONL 导入器。
